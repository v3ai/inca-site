One application, the whole pipeline

From the first polygon to the final frame

Model, rig, animate, shade and render in one window, with construction history that keeps every step editable.

Modeling

Polygon and NURBS modeling with live history

Extrude, bevel, bridge, multi-cut, booleans, quad draw and sculpting brushes, all on n-gon meshes. Every primitive and operation stays in the Channel Box's INPUTS, so you can change a bevel's segments long after you made it.

  • Twelve primitives, smooth mesh preview and symmetry
  • CV, EP, pencil and three-point arc curves; revolve, loft and extrude
  • UV projections and a UV Editor with unfold and layout
Animation

Keyframes, curves and rigs

Set keys with S, scrub the Time Slider and shape motion in the Graph Editor with tangent handles and infinity modes. Build skeletons with IK, bind skin, paint weights and drive it all with constraints, deformers and set driven keys.

  • Graph Editor, Dope Sheet, ghosting and motion trails
  • Joints, IK handles, smooth bind and blend shapes
  • Playblast to WebM video or a PNG sequence
Look development

Materials in the Hypershade

Create Standard Surface, Lambert, Blinn and Phong materials, wire textures into them in the node graph and drag them straight onto objects. File textures accept HDR and EXR images.

  • Checker, ramp, noise, grid and file textures
  • Bump, roughness, metalness and emission maps
  • Per-face material assignment
Rendering

A physically based path tracer built in

Render the current frame from any camera, compare snapshots in the Render View, or batch a sequence to your project's images folder. When you need speed, switch to Inca Hardware for anti-aliased rasterized frames with soft shadows.

  • Directional, point, spot, area and sky dome lights
  • IPR, exposure and gamma controls, keep and compare images
  • Render Settings for size, samples, bounces and tone mapping
Scripting

MEL and JavaScript, echoed as you work

Every menu item and tool prints the command it ran, so you can copy it into the Script Editor and turn it into a shelf button. Write MEL with procedures and loops, or use the JavaScript cmds API.

// Build a row of spheres
for ($i = 0; $i < 5; $i++) {
    polySphere -r 0.5;
    move ($i * 1.5) 0.5 0;
}

Download

Get Inca

No installer and no sign-up. Download the file, run it and start modeling.

Windows

64-bit, Windows 10 or newer. The portable exe runs without installing anything.

Portable .exe .zip archive

If SmartScreen appears, click More info, then Run anyway.

Linux

64-bit AppImage that runs on most distributions. Make it executable, then double-click it.

AppImage 
chmod +x Inca-*.AppImage
./Inca-*.AppImage

On Ubuntu 22.04 or newer you may need sudo apt install libfuse2.

macOS

No ready-made download yet. Run it from source with Node.js 18 or newer; it takes about five minutes.

Run from source 
git clone https://github.com/v3ai/inca
cd inca && npm install && npm start

Free 3D modeling, animation and rendering.

Inca is an open-source desktop app that works like Maya 2020. The menus, hotkeys and marking menus are where you expect them, and every step keeps its construction history.

Download Source code

Windows and Linux · MIT license

Modeling

Polygon modeling on n-gon meshes: extrude, bevel, bridge, multi-cut, booleans, quad draw and sculpting brushes. NURBS primitives and CV, EP, pencil and arc curves, with revolve, loft and extrude. Change any input in the Channel Box later and the result updates.

Animation and rigging

Keyframes, the Graph Editor and Dope Sheet, motion paths and set driven keys. Joints with IK, smooth bind and weight painting, constraints, deformers and blend shapes. Playblast to video or images.

Shading

Standard Surface, Lambert, Blinn and Phong materials, connected to file, checker, ramp, noise and grid textures in the Hypershade.

Rendering

A built-in path tracer and a faster hardware renderer. Render one frame in the Render View or a sequence to the project's images folder.

Scripting

Every action prints the MEL command it ran. Run MEL or JavaScript in the Script Editor and save scripts to the shelf.

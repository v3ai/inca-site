# Inca website

The website for [Inca](https://github.com/v3ai/inca), a free, open-source 3D modeling, animation and rendering application.

Live at https://incacad.com.

Plain HTML, CSS and JavaScript with no build step, published with GitHub Pages from the `main` branch.
The download buttons read the latest release from the GitHub API, so they update by themselves when a new version ships.
To preview locally, run `python3 -m http.server` in this folder and open http://localhost:8000.

The screenshots in `img/` were taken in the app itself.
